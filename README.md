# VALORANT Aim Trainer

面向无畏契约玩家的独立网页鼠标控制训练工具。

## 使用
下载 mouse_precision_trainer.html，使用桌面浏览器打开，选择项目并开始训练。移动鼠标碰到目标即可触发，无需点击。成绩保存在浏览器本地。

## 当前功能
- 反应点靶、追踪稳定、精细控制
- 自定义准星和目标大小
- 实时倒计时、训练报告和最近成绩

## 当前限制
本版本尚未实现游戏灵敏度生成，也没有内嵌 7EBMG8B 或官方 Aim Lab 测试。它不能将浏览器鼠标表现直接换算成游戏内最佳灵敏度。

本项目与 Riot Games 和 Aim Lab 无关联，不读取或修改游戏文件。
